# CocardoAddon

CocardoAddon is a Minecraft plugin designed to collect, display, and manage cocardos, which are customizable items or badges that players can wear or share. This plugin allows players to create, equip, and share cocardos with other players, enhancing the customization and social aspects of the game.

## Install

1. Download the plugin JAR file from the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart the server to load the plugin.

## Use

1. **Display your cocardos**: Use the command `/cocardos` to view your collection of cocardos.
2. **Equip a cocardo**: Use the command `/equip <cocardo>` to wear a specific cocardo.
3. **Share a cocardo**: Use the command `/share <player> <cocardo>` to give a cocardo to another player.
4. **Create a custom cocardo**: Use the command `/create <design>` to create a new cocardo with a custom design.
